# Description

This frontend provides the user interface for the **El Arte de la Hipertrofia Muscular** MVP.

The application connects to a Spring Boot backend through REST APIs and allows users and trainers to interact with the hypertrophy tracking platform.

The frontend supports:

* User registration
* Trainer registration
* Authentication with JWT
* User dashboard
* Trainer dashboard
* Training registration
* Recovery tracking
* Nutrition tracking
* Wellness tracking
* Progress visualization
* Recommendation visualization

# Current Features

## Authentication

The frontend supports:

### User Registration

Allows creating new users with:

* name
* email
* password
* mode (SELF_MANAGED / SUPERVISED)

### Trainer Registration

Allows creating trainer accounts with:

* name
* email
* password

### Login

Users and trainers can authenticate using:

* email
* password

After login:

* JWT token is stored in localStorage
* User information is stored locally
* Dashboard access is enabled

---

# User Features

Authenticated users can:

### Register Training Sessions

Track:

* date
* muscle group
* exercises
* intensity
* duration

### Register Recovery Check-ins

Track:

* fatigue
* soreness
* energy
* sleep hours
* recovery notes

### Register Nutrition Entries

Track:

* calories
* protein
* carbohydrates
* fats
* hydration

### Register Wellness Check-ins

Track:

* physical state
* mental state
* emotional state
* stress level
* motivation level

### View Progress Summary

Displays summarized information generated by the backend:

* trainings
* recovery
* nutrition
* wellness

### View Recommendations

Displays recommendations generated by trainers and stored by the backend.

---

# Trainer Features

Authenticated trainers can:

### View Supervised Users

Display users assigned to the trainer.

### View User Progress

Access progress information of supervised users.

### Create Recommendations

Generate recommendations for assigned users through backend endpoints.

# JWT Authentication

The frontend uses JWT authentication provided by the backend.

After login:

```text
localStorage
├── token
├── role
├── id
├── name
└── email
```

Authenticated requests include:

```http
Authorization: Bearer <token>
```

# Backend Integration

The frontend consumes the following backend endpoints:

## Authentication

```http
POST /api/auth/register-user
POST /api/auth/register-trainer
POST /api/auth/login
```

## Users

```http
GET /api/users/me
POST /api/users/{userId}/assign-trainer/{trainerId}
```

## Training

```http
POST /api/trainings
```

## Recovery

```http
POST /api/recovery-checkins
```

## Nutrition

```http
POST /api/nutrition-entries
```

## Wellness

```http
POST /api/wellness-checkins
```

## Progress

```http
GET /api/progress-summary/me
GET /api/progress-summary/trainers/me/users/{userId}/progress
```

## Trainers

```http
GET /api/trainers
GET /api/trainers/me/users
```

## Recommendations

```http
GET /api/recommendations/me
POST /api/recommendations/trainers/me/users/{userId}
```

# Known Limitations

Current MVP limitations:

* Trainer assignment still depends on backend assignment workflow.
* Dashboard visualizations are basic.
* No charts are currently implemented.
* No notification system.
* No real-time updates.
* No advanced trainer management panel.
* No admin module.
